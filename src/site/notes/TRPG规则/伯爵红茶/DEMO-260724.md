# 世界观
~~基本上就是无光深空加上黑鸟夫人~~
女皇陛下的舰船在以太中航行，帝国的疆域跨越一层又一层的天球; 在群星加身的荣光下，每一位帝国的子民都能自豪地说: 凡是太阳能照到的地方，就一定会有帝国的蒸汽机在轰鸣。

- **以太天球**: 以太充盈着天野，无数天体悬浮其中; 天空划分为四层天球与三大星团，分别绕太阳运行。
- **星系，迷你版**: 天佑的女皇陛下将首都带往第二天球，也创造了空中最大的天体; 一艘客运飞艇也仅需数周，就能造访这个庞大帝国最遥远的边疆。
- **当然，还有蒸汽**: 齿轮，煤炭，轰鸣的锅炉房和创造了万千岗位的大工厂!

# 你
你们是比商人、海盗、走私者和间谍还要特殊的存在，因为你们掌握*权衡术*。依帝国签发的证件，你们是*特使*: 每个人都希望得到你们的帮助，但没有人想和你们扯上关系。

> [!NOTE] *权衡术*
> 帝国带来了统一，但统一带来失衡; 三克拉宝石只是首都贵族一枚袖扣，却与殖民地矿工三周的血汗等重。游离在体制边缘的你们深谙这一点， 并将运用这种失衡的技艺称为"权衡术": 只需在产地为物定权，当物被带至他处遭受重新审视后，你就能借助其中的失衡唤起物所缺失的力量。
> > [!example] 
>> 一桶时间从源头隅纳送至帝国首都不会流逝分毫，但如若特使在隅纳对这桶时间定权，又在首都将失衡兑现，他就能短暂地释放曾在隅纳照耀着这桶时间的炽热阳光。
## 特使生活
- **特事特办**: 帝国忌惮特使，也需要特使。天野中太多力量超出了猞猁学院的理解，特使至少是可以共事的一股。
- **终生债务**: 鲜为外人所知的是，权衡术本身也来自于失衡。特使早已把人生放上天平，永远都在不可避免地滑向他的债务: 熊熊燃烧的野心，魔鬼交易的代价，或是亲手铸就的错误。
- **无以为乡**: 特使在某处逗留越久，他就越是迟钝，失去对平衡的感知。特使不得不踏上旅程，一次又一次。
