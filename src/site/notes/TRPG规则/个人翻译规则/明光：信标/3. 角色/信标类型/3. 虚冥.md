- *明光既可以慷慨，也可以无情*
- *踏足此界与彼界的隙间*
- *用虚无吞没敌人*
光时常会唤起明亮的希望，许多信标也致力于此，为人类带来明亮的希望。但是凡事总有两面，光所不在的地方仍有事物潜藏。

虚无中一切都会消逝，即便是时间本身。而你，你是虚无领域的织匠，足以扭曲现实，让世界在你面前俯首。

你的同伴根本没有意识到虚无中所存在的无尽能量，要是他们能抛开那些根深蒂固的观念，探索虚空该有多好——这样，你又能扭曲更多存在了。

### 空无
*状态*: 用虚空之光笼罩敌人。空无影响的目标会受到存在恐惧与世界本身的重压，无法行动。

### 衡势
*被动*: 虚空既会索取，亦会给予，维系平衡。每当你行动时毗邻其他信标，就能让他们恢复1点生命或造成1点额外伤害。

### 吞噬
*近战*: 虚空张开血盆大口攫取所及之物。对毗邻目标造成1点伤害并施加**空无**。如果目标死亡，恢复1点生命。

# 能力
###  引力炸弹
投掷一团巨大的虚无能量。对目标造成5点伤害，毗邻目标的所有敌人受到1点伤害。所有受影响的敌人获得**空无**。

### 熵
将所有虚空之光召回体内。每个受**空无**影响的敌人失去1点生命，而每以此法致一个敌人失去生命，就恢复1点生命。

### 步入虚无
在存在与虚无的间隙行走，闪现而出时炸开虚空之光。移动至多3次。每次出现都能对毗邻敌人造成1点伤害并施加**空无**。

# 节点
- 揭示一个虚空之光的秘密
- 展现光与暗的平衡
- 湮灭灯塔的威胁
- 展现无尽虚空的恐惧
- 证明虚无无处不在
- 让另一位信标给出光能
- 扭曲现实以满足自我
- 为他人承担重负
