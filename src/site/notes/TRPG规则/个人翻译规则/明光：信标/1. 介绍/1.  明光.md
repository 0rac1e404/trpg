# 简介
***《明光》*** 是一款TRPG，在其中，永恒不灭的卫士们守护着地球最后之城。它们是*信标*，身负明光的力量，屹立在人类前方，抵抗企图灭除一切的黑暗势力。

只要同心协力，你们将谱写反抗与希望的赞歌，跨越星系，击退黑暗。但使明光不灭，信标永恒闪耀。

# 准备
你需要这个规则，角色卡以及笔。你还需要D6骰子，最好有着两种不同样式，便于区分。

***《明光》*** 适合2-5名玩家游玩，通常一次团需要2小时左右。

# 职责
玩家有着两种不同的职责:
- 大多数玩家将会扮演*信标*，满溢明光的人类卫士。信标互不相同，以独有的方式运用光能。扮演信标时，你需要:
	- 塑造你的角色
	- 描述你如何行事
	- 保卫太阳系
- 一位玩家将成为*GM*，运行整个游戏。他需要:
	- 运行信标的任务
	- 呈现世界的环境、盟友与敌人

# 明光: 信标
***《明光》*** 最初于2020年发布，此后历经数次扩展与修改。这本 ***《明光: 信标》*** 是最终版本，收录了大部分扩展规则，并将核心规则重新整理更新。
